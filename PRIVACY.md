# Privacy Policy

_Last updated: 2026-11-02_

This policy explains what data the Aion2-LFG Discord bot ("the bot") stores and why.

## 1. Data the bot stores

The bot only stores what it needs to run events and groups:

- **Server settings:** server ID, the channel IDs for events and groups, the configured timezone, and the organizer role ID.
- **Events and groups:** server, channel and message IDs, the Discord user ID of the creator, title, description, start time, status and creation time.
- **Sign-ups and members:** your Discord user ID, the AION 2 class you picked, your slot in a group, and when you signed up or joined.

The bot does **not** store message content, usernames, email addresses, IP addresses, or anything from your Discord profile beyond your user ID.

## 2. How the data is used

The data is used only to show and update event and group posts, and to manage sign-ups. It is not sold, shared with third parties, or used for advertising or tracking.

## 3. Where the data is stored

Data is kept in a database on the server that runs the bot. Discord itself also processes your interactions according to the [Discord Privacy Policy](https://discord.com/privacy).

## 4. How long data is kept

Data is kept as long as it is needed for the event or group it belongs to. Server settings are kept while the bot is on the server. Ended, cancelled or closed events and groups may be deleted automatically.

## 5. Your rights

You can remove your sign-up from an event or leave a group at any time with the bot's buttons. To ask for a copy of your data or have it deleted, open an issue in this repository (without posting personal data in it) and you will be contacted for the details. Server administrators can remove all of their server's data by asking the same way.

## 6. Changes

This policy may be updated. The current version is always available in this repository.

## 7. Contact

Questions about this policy can be raised by opening an issue in this repository.
